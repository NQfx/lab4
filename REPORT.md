# REPORT.md — Лабораторная работа №4: Ансамбли и полносвязные сети

## 1. Данные и подготовка
- **Датасет:** `german.csv` (разделитель `;`), целевая переменная — `Creditability`.
- **Очистка:** удаление строк с пропусками (`dropna`), затем отсечение выбросов по квантилям (2 % с каждой стороны).
- **Split:** случайное перемешивание (`random_state=42`), 80 % — train, 20 % — test.
- **Масштабирование:** `StandardScaler`, обученный **только на train** (fit на train, transform на test) — утечки нет.
- **Признаки:** исходные признаки датасета, дополнительного feature engineering не применялось.

## 2. Гипотезы и эксперименты
1. **Базовые модели по отдельности** (`test_models.py`): LogReg, KNN, Decision Tree, Gradient Boosting, Random Forest, Extra Trees, HistGradientBoosting — чтобы понять потолок одиночных моделей.
2. **Стекинг** (`ensemble_models.py`): базовые модели **Gradient Boosting + Random Forest + Logistic Regression**, мета-модель — **Logistic Regression**.
   - Мета-признаки строятся через **out-of-fold** предсказания (5-fold KFold, `shuffle=True`, `random_state=42`) — это исключает утечку при обучении мета-модели.
   - Гиперпараметры базовых моделей: GB (`n_estimators=300, lr=0.05, max_depth=4, min_samples_leaf=5, subsample=0.8`), RF (n_estimators=500, max_depth=10, min_samples_leaf=3).

**Критерий выбора:** основной — **ROC-AUC** (по вероятностям, а не бинарным предсказаниям), т.к. именно он определяет оценку в задании.

## 4. Выбранная модель
Выбран **стекинг GB + RF + LR с мета-моделью Logistic Regression**.
- ROC-AUC = **0.8329** — лучший результат, выше любой одиночной модели
- Комбинация разнородных моделей (бустинг + бэггинг + линейная) снижает дисперсию и даёт более устойчивые вероятности.
- По шкале задания (ROC-AUC > 0.80) — **10 из 10 баллов**.

## 5. Выводы и ограничения
- **Улучшило результат:** стекинг разнородных моделей и корректные OOF-признаки для мета-модели.
- **Ухудшило/слабое место:** Decision Tree (ROC-AUC 0.60) сильно тянет вниз; KNN даёт высокий Recall, но низкий Precision.
- **Ограничения:** небольшой датасет, простой отсев выбросов по квантилям, гиперпараметры подбирались вручную
